Terminal setup guide →

Add this snippet to your Claude Code statusline command to see the estimated API cost update in real time as you work — so you know exactly what you're saving each session.

# In your statusline command (receives JSON via stdin):
cost=$(jq -r '.cost.total_cost_usd // 0')
printf '~$%.2f\n' "$cost"

Paste this into your ~/.claude/statusline-command.sh. Claude Code pipes JSON to the statusline command on every render. This uses its cumulative session cost, so earlier requests keep their original rates when the prompt size or model changes. See the statusline documentation.
