Hobbyist approved

A complete development stack that costs nothing to start. Perfect for side projects, MVPs, and learning.

IDE

Free tiers

Your coding environment - where you write and edit code with AI assistance.

> Firebase Studio - Google's cloud IDE + Gemini. 3 free workspaces.
> Windsurf - AI-first VS Code fork. Best free AI tier.
> Zed - Fastest editor (Rust). Free, open source.
> Cursor - AI-native VS Code fork. 50 free requests/mo.
> GitHub Copilot - Works in VS Code. Free tier: 2K completions/mo.
01

AI app builders

Free / Paid

Describe what you want, get a working app. Great for prototypes and MVPs.

> Google AI Studio - Prototype with Gemini. Export to Firebase Studio.
> Bolt.new - Full-stack apps in browser. StackBlitz powered.
> v0 by Vercel - React UI from prompts. Image-to-code. Free tier.
> Lovable - No-code app builder. Plain English -> full app.
> Replit - Cloud IDE + AI Agent. Free starter plan.
02

AI documentation

Open source

Auto-generate docs for your codebase. Saves hours of manual documentation work.

> SuperDocs - AI-powered documentation generation, 100% free & open source.
03

Database

Free tier

Store your app's data. Both options include real-time sync and easy setup.

> Firebase - Google's BaaS. Free tier or pay-as-you-go.
> Supabase - Open source Firebase alt. Nano plan free.
04

Authentication

Free up to 10K

User login, signup, OAuth, magic links. Handle auth without building it yourself.

> Stack Auth - Open source Auth0/Clerk alt. Free up to 10K users.
05

LLM (AI model)

Free / Low cost

Add AI capabilities to your app. Multiple options for testing and production.

> OpenRouter - Unified API for multiple LLMs. Pay per use.
> Gemini AI Studio - Free testing with Google's Gemini models.
> Unsloth AI - Fine-tune models 2x faster in Google Colab.
06

Version control

100% free

Track changes, collaborate, and never lose your work. Essential for any project.

> GitHub - Industry standard. Free unlimited repos.
> GitLab - Open source. Self-host option. Built-in CI/CD.
07

Deployment

Free tier

Get your app live in minutes. Push to git, auto-deploy to the world.

> Vercel - Deploy frontend & serverless in seconds.
> GitHub Pages - Free static site hosting. Perfect for docs.
> Cloudflare Pages - Fast global CDN. Unlimited bandwidth free.
> DigitalOcean - VPS droplets from $4/mo. Full server control.
08

DNS & CDN

100% free

Domain management, SSL, caching, and DDoS protection. Essential infrastructure.

> Cloudflare - Free DNS, SSL, CDN, DDoS protection. Industry standard.
09

Analytics

All free

Understand your users. Use all three for complete visibility.

> PostHog - Product analytics, session replays, feature flags.
> Microsoft Clarity - Heatmaps & recordings. 100% free.
> Google Analytics - Traffic & conversions. Industry standard.
10

Maps & geo

100% free

Interactive maps for data journalism and location-based projects.

> Leaflet - Lightweight JS maps. OpenStreetMap tiles free.
> Mapbox - Custom map styles. 50K loads/mo free.
11

Web scraping

Open source

Extract data from websites. Essential for data journalism and research.

> Playwright - Browser automation. Handles JS-heavy sites.
> Trafilatura - Python content extraction. Clean article text.
> yt-dlp - Download video/audio from 1000+ sites.
12

Desktop apps

Open source

Build native desktop apps using web technologies you already know.

> Electron - JS/HTML/CSS -> Windows, Mac, Linux apps.
> PyWebView - Python + HTML/CSS desktop GUIs. Lightweight.
> Tauri - Rust backend + web frontend. Tiny binaries.
13

AI coding CLIs

Free / Usage

Code with AI in your terminal. Agentic tools that read, write, and execute.

> Claude Code - Anthropic's agentic CLI. Max plan = unlimited.
> Gemini CLI - Google's CLI. Free tier with Gemini models.
