# _archive/

Inactive material kept in the repo for reference. Nothing here is deployed or linked from the live site (`tools.amditis.tech` serves only `resource-kit/docs/`).

## design-library/

Four iteration files of the Amditis design system (`SYSTEM_KIT_v2.5`, v2 untitled, `RAW_v3.0`, `SPECTRUM_v4`). Exploration artifacts from January 2026, never wired into any deployed page. Kept for visual reference; do not link from production.

## context/

Raw source material: vibe-coding starter guide draft, LLM-advisor early prototype, YAP tool homepage aesthetic study, frontend aesthetics notes, playground review notes. Inputs to design and writing decisions, not deliverables.

## When to add here

Move things here instead of deleting when:

- The file is a saved iteration of something that has since shipped (and the shipped version lives elsewhere)
- The file is research / inspiration / raw export that informed a deliverable
- The file is provably unlinked from any deployed surface

If a file is truly dead and not worth preserving, delete it — git history retains it.
